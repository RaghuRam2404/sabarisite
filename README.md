# TeamSabari - Bodybuilding Coach Website

Professional single-page website for TeamSabari bodybuilding coach.

## Features

- Full-screen hero with trainer photos and achievements
- Services pricing (Competition Prep, Personal Training, Online Training)
- Transformation gallery with before/after photos
- Fully responsive design
- Optimized for mobile performance
- Instagram integration

## Setup

1. Add your images to the main folder:
   - `trainer-main.jpg` - Hero photo
   - `favicon.png` - Site icon
   - `pose-*.jpg` - 6 posing photos
   - `transformation-*.jpg` - Before/after photos

2. Update content in `index.html`:
   - Trainer name and bio
   - Achievement badges
   - Pricing
   - Instagram links (search for `ig.me/m/sabarisri_ram`)

3. Open `index.html` in a browser or run:
   ```bash
   python3 -m http.server 8000
   ```

## Deployment

### GitHub Pages (Free)
1. Create GitHub repository
2. Upload all files
3. Enable Pages in Settings
4. Live at: `https://username.github.io/repo-name`
